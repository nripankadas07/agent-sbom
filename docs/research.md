# Research notes

The design is informed by:

- [CycloneDX 1.6](https://cyclonedx.org/docs/1.6/json/) for component inventory.
- [SARIF 2.1.0](https://docs.oasis-open.org/sarif/sarif/v2.1.0/) for code-scanning interchange.
- [MCP security best practices](https://modelcontextprotocol.io/docs/tutorials/security/security_best_practices) for authorization and proxy risks.
- [OWASP Agentic Security Initiative](https://genai.owasp.org/initiatives/agentic-security-initiative/) for tool misuse and agent supply-chain risk.

External specifications are referenced, not copied. The capability vocabulary
and deterministic evidence artifact are project-specific and versioned.
